## Edit

Edit `index.html`, `styles.css`, and `script.js`. `projects.json` is a content reference; the HTML is static and is not dynamically generated from this file. No package install or build is needed for GitHub Pages.

## GitHub Pages

Upload the contents of this folder to the portfolio repository root. The included workflow deploys the static files from that root on a push to `main`. Keep Pages set to GitHub Actions. All asset paths are relative and support project subpaths. The contact button opens the visitor’s email application.

## Features

Responsive layout, keyboard-accessible navigation, mobile menu, persistent light/dark theme, project-category filters, expandable contribution details, reduced-motion support, and downloadable résumé. All project content remains visible when JavaScript is disabled.
